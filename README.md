# Digital-Forensics-Portfolio

# Case Overview

This investigation involved the forensic analysis of a disk image to identify potential misuse of cloud storage services.

## Objectives
- Identify hidden or deleted artifacts
- Analyze sync logs
- Recover concealed data
- Verify file integrity

## Methodology
1. Disk image mounted in Autopsy
2. File system browsing and metadata extraction
3. Prefetch file analysis
4. String extraction on .oxps files
5. Hash verification
6. Cross-correlation with network artifacts

## Key Findings
- 52 executions of cloud sync application
- Hidden data in alternate streams
- Embedded messages within steganographic images
- Encoded content detected in network traffic

## Conclusion
Findings suggest intentional obfuscation of digital artifacts.
