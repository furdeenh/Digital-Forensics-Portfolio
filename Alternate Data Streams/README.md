# Alternate Data Streams (ADS) Investigation

This case focused on identifying hidden data embedded within NTFS Alternate Data Streams (ADS) attached to standard document files.

## Objectives
- Detect hidden ADS attached to .docx files
- Extract concealed stream content
- Compare hash values for file integrity
- Determine whether hidden streams indicate intentional obfuscation

## Skills Demonstrated
- NTFS file system analysis
- ADS detection using forensic tools
- Hash validation (SHA-256)
- Hidden metadata recovery
- Insider threat detection methodology
