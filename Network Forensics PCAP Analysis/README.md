# Network Forensics – PCAP Analysis

This investigation analyzed multiple packet capture files to identify covert communication, encoded payloads, and sensitive data exposure.

## Objectives
- Reconstruct TCP streams
- Extract HTTP objects
- Decode base64 content
- Identify exposed sensitive data
- Analyze multicast UFTP transfers

## Skills Demonstrated
- Wireshark TCP stream reconstruction
- HTTP object extraction
- Payload decoding
- Protocol hierarchy analysis
- Multicast traffic analysis
